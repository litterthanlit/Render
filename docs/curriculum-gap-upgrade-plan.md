# Curriculum Gap Upgrade Plan

Purpose: turn the benchmark gaps into concrete curriculum work that is visible in the app and reviewable by mentors.

## Added Curriculum Phases

1. Product Discovery & Research
   - Adds problem framing, assumptions, constraints, lightweight research, success signals, prototype briefs, and critique questions.
   - Evidence: research-backed prototype brief.

2. Figma-to-Code Systems
   - Adds Figma variables, token mapping, component-property-to-prop mapping, responsive handoff, Storybook coverage, and governance.
   - Evidence: Figma-to-code system handoff.

3. Testing & Quality Assurance
   - Adds unit, component, end-to-end, visual, accessibility, performance, CI, and release evidence planning.
   - Evidence: QA and release evidence pack.

4. AI-Assisted Design Engineering
   - Adds responsible prompting, generated UI review, system-fit checks, accessibility checks, code-quality review, verification, and portfolio disclosure.
   - Evidence: AI output review pass.

## Capstone Changes

The capstone should now require:

- Research-backed prototype brief.
- Figma-to-code handoff.
- Storybook or equivalent component documentation.
- Testing and QA evidence.
- Accessibility and performance evidence.
- AI process note if AI was used.
- Deployed URL, GitHub repo, README, case study, and final reflection.

## Mentor Checkpoints

- Discovery brief critique.
- Figma handoff review.
- Storybook/governance critique.
- QA plan review.
- AI output review critique.
- Capstone kickoff, milestone review, and final portfolio review.

Each checkpoint needs a submitted artifact, rubric, action items, and final status.

## Launch Priorities

1. Make the new phase pages visible and reviewable in curriculum review mode.
2. Replace placeholder mentor copy with concrete rubric language.
3. Add real examples for Figma handoff, QA evidence, and AI output review.
4. Add actual Storybook/testing integrations after the written curriculum is validated.
5. Revisit early-phase ordering later if discovery should move before React for cohorts.

## Success Standard

A reviewer should be able to open the curriculum and see how a learner moves from implementation basics to product framing, Figma systems translation, measurable QA, responsible AI use, and a stronger capstone.
